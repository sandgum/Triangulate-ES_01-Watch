# How to Manufacture the PCB

1. Go to the folder `PCB/Production Files`

2. Find the zip file named `ES_01_mainPCB-vxx.zip`

3. Upload the zip file to JLCPCB (or your preferred PCB manufacturing site), DO NOT expand the file

4. If you are using JLCPCB, follow these next instructions:
   
   1. **Set Base Material to Flex**
   
   2. Set Substrate Type to 25um dielectric thickness
   
   3. **Set Layers to 4**
   
   4. Leave Dimensions unchanged (They should be greyed out anyways)
   
   5. **Set PCB Qty to 5**
   
   6. Leave Different Design and Delivery Format unchanged
   
   7. **Set PCB Thickness to 0.2mm**
   
   8. Set Coverlay Color to whatever you want! (Yellow is the cheapest btw)
   
   9. Leave Silkscreen, Copper Type, Surface Finish and Gold Thickness unchanged
   
   10. Leave Outer Copper Weight, Inner Copper Weight, Specify Layer Sequence, Stackup Type, Layer Stackup, Coverlay Thickness and Gold Fingers unchanged
   
   11. Set EDA Software to Other
   
   12. **Set Stiffener to FR4**
   
   13. **Set FR4 Thickness to 0.1mm**
   
   14. Leave Cutting Method and Confirm Production file unchanged
   
   15. Set Mark on PCB to Order Number
   
   16. Leave everything else unchanged
   
   17. At the very bottom, select PCB Stencil. In its settings:
       
       1. Leave Framework, Step Stencil and Nano-coating unchanged
       
       2. **Set Stencil Style to Top only**
       
       3. Leave Dimensions unchanged
       
       4. **Set Stencil Qty to 1**
       
       5. Leave everything else unchanged
   
   18. Click Save to Cart, and you're done!
